# GARDN-M
Working project for development of an automated GARDN-M model, originally for APS-DPP

## October 2026 update
The input data was refreshed in October 2026 with newer editions of existing sources, new sources, and recent summary reports. The new data is in `data/processed_data_2026/` and `data/sources_2026/`; the original data is unchanged in `data/processed_data/` and `data/sources/`. See [docs/oct2026_update/README.md](docs/oct2026_update/README.md) for what changed, how to run each version, and how the results compare.
